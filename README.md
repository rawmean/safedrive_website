# SafeDrive Website

Official website for **SafeDrive** — family driving safety for iPhone and iPad.

> Drive Safer. Stay Connected.

SafeDrive shares a driver's live speed and location with the family members
they invite, sends instant speeding alerts, and keeps a map-based history of
every trip.

## Pages

| Page | Description |
| --- | --- |
| `index.html` | Landing page — hero, features, screenshots, privacy/support links |
| `privacy.html` | Privacy policy (own URL) |
| `support.html` | Support page with email button and FAQ |
